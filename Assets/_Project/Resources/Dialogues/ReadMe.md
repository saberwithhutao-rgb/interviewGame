# 对话系统配置文档

## 一、这是什么

我们用一张 Excel 表来写游戏里的所有对话。写完导出成文本文件，游戏会自动读取并显示。

不需要写代码，只需要填表。

---

## 二、表格长什么样

打开 `Dialogues.xlsx`，第一行是表头，不能删、不能改。

| 列名 | 填什么 | 必填 |
|------|--------|------|
| rowType | 这一行是对话还是选项 | ✅ |
| id | 这一行的编号，不能重复 | ✅ |
| speaker | 谁在说话 | ✅ |
| content | 说话内容 或 选项文字 | ✅ |
| nextId | 下一句的编号 | ✅ |
| conditionType | 显示条件（暂时留空） | ❌ |
| conditionValue | 条件的值（暂时留空） | ❌ |
| effectType | 执行效果（暂时留空） | ❌ |
| effectValue | 效果的值（暂时留空） | ❌ |

---

## 三、rowType 只能填两个值

| 值 | 含义 |
|----|------|
| `line` | 普通对话，说完自动跳下一句 |
| `option` | 选项，让玩家选 |

---

## 四、id 和 nextId 怎么填

- **id 必须唯一**，不能有两行用同一个 id
- **id 建议从 1 开始连续编号**，方便管理
- **nextId 填下一句的 id**
- **nextId = -1 表示对话结束**

---

## 五、选项怎么填

选项要满足两个规则：

**规则 1：选项的 id 必须连续**

比如选项是 4、5、6，不能是 4、5、7。

**规则 2：选项前面必须有一句 line 指向第一个选项**

比如：

| rowType | id | speaker | content | nextId |
|---------|----|---------|---------|--------|
| line | 3 | sword | 我需要你的帮助 | 4 |
| option | 4 | 玩家 | 可以 | 7 |
| option | 5 | 玩家 | 拒绝 | 8 |
| option | 6 | 玩家 | 考虑 | 9 |

第 3 行的 `nextId = 4`，指向第一个选项。游戏会自动把 4、5、6 全部显示为选项。

## 七、填写注意事项

| 注意 | 说明 |
|------|------|
| 不要删表头 | 第一行必须保留 |
| 不要改列名 | 列名必须和文档一致 |
| id 不要重复 | 重复会导致对话错乱 |
| 选项 id 要连续 | 否则选项会显示不全 |
| nextId 要指向真实存在的 id | 否则会跳转失败 |
| 对话内容里不能有 Tab 键 | Tab 是分隔符，会破坏格式 |
| 中文用 UTF-8 编码 | 否则会乱码 |

---

## 八、怎么导出

1. 在 Excel 里写完
2. 文件 → 另存为
3. 格式选 **"文本（制表符分隔）(*.txt)"**
4. 编码选 **UTF-8**
5. 保存到 `Assets/Resources/Dialogues/` 目录下
6. 游戏运行时自动读取
